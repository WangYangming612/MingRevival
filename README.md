# 南开大学 高级语言程序设计大作业
## 崇祯救明：大明中兴模拟器

### 项目介绍
本项目是基于 C++ / Qt 开发的历史策略模拟游戏。
玩家扮演崇祯皇帝，在36个月内处理政务、应对历史事件、平衡国家属性，
尝试挽救明朝，实现大明中兴。

### 开发环境
- 编程语言：C++17
- 图形框架：Qt 6
- 开发工具：Visual Studio 2022
- 版本控制：Git & GitHub

### 核心功能
1. 属性系统（体力、智力、魄力、识人、国库、民心、军心等）
2. 政务处理系统（13种政务，带属性判定与成功/失败效果）
3. 历史事件系统（15个真实明末事件，双选项决策）
4. 月度财政与势力自动增长系统
5. 多结局游戏胜利/失败判定
6. 纯代码古风UI美化（QSS）
